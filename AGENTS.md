# AGENTS.md

Engineering skills configuration for this repo.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `zengsipei/z-claude-plugins`; the `gh` CLI is used for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` — each label name equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

single-context: one root `CONTEXT.md` plus `docs/adr/`; no `CONTEXT-MAP.md`. See `docs/agents/domain.md`.
